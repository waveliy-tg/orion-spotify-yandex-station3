# Orion — Spotify на Яндекс Станции 3

**Orion** — проект для использования Spotify на **Яндекс Станции 3**. Взаимодействие со Spotify осуществляется через API с использованием **Soloist**.

> **Важно:** проект предоставляется «как есть». Голосовые команды не работают.

## Как это работает

Orion использует API Spotify через Soloist. Колонка определяется как:

```text
Yandex Station 3 Soloist
```

Ищите это имя при выборе устройства для воспроизведения.

## Подготовка

- Яндекс Станция 3 с Orion, root-доступом и доступными подключениями ADB и SSH.
- Компьютер с Windows, Python 3, ADB (`adb.exe`) и SSH-клиентом.
- Файлы установщика в одной папке: `soloist_orion.py`, `orion_transport.py`, `runtime_manifest.json`, `soloist.sh`, `cacert.pem`.
- Файл `soloist_autostart.sh` для настройки автозапуска.
- Личный API-ключ Soloist: установщик запросит его в терминале со скрытым вводом.
- Доступ к интернету для загрузки Soloist и необходимых библиотек.

**Во всех командах замените `IP_КОЛОНКИ` на IP-адрес вашей колонки.** Порт SSH в примерах — `2222`; если у вас другой порт, замените его. Команды выполняйте в PowerShell из папки с файлами установщика, если не указано иное.

## Установка

### 1. Установите Soloist через ADB

```powershell
py -3 soloist_orion.py IP_КОЛОНКИ install
```

Указывается именно IP-адрес колонки. При таком подключении установщик использует порт ADB `5555`. Если порт ADB отличается, укажите адрес в формате `IP_КОЛОНКИ:ПОРТ_ADB`:

```powershell
py -3 soloist_orion.py IP_КОЛОНКИ:ПОРТ_ADB install
```

Дождитесь завершения установки и введите личный API-ключ Soloist по запросу. На колонке требуется не менее 600 МБ свободного места в `/data`.

### 2. Настройте автозапуск через SSH

После успешной установки Soloist выполните в PowerShell:

```powershell
Get-Content -Raw -Encoding UTF8 .\soloist_autostart.sh | ssh -p 2222 root@IP_КОЛОНКИ "tr -d '\r' | sh"
```

### 3. Один раз перезагрузите колонку

```powershell
ssh -p 2222 root@IP_КОЛОНКИ reboot
```

Дождитесь загрузки колонки и подключения к сети. В Spotify выберите **Yandex Station 3 Soloist**. Телефон и колонка должны находиться в одной сети Wi-Fi.

**Повторно выполнять `install` у `soloist_orion.py` не требуется.**

## Управление

Подключитесь к колонке из PowerShell:

```powershell
ssh -p 2222 root@IP_КОЛОНКИ
```

**Следующие команды вводятся уже в SSH, на колонке:**

| Действие | Команда |
| --- | --- |
| Запустить сейчас | `sh /data/spotify-soloist/autostart.sh start` |
| Остановить сейчас | `sh /data/spotify-soloist/autostart.sh stop` |
| Перезапустить | `sh /data/spotify-soloist/autostart.sh restart` |
| Проверить состояние | `sh /data/spotify-soloist/autostart.sh status` |
| Посмотреть логи | `sh /data/spotify-soloist/autostart.sh logs` |
| Включить автозапуск | `sh /data/spotify-soloist/autostart.sh enable` |
| Отключить автозапуск | `sh /data/spotify-soloist/autostart.sh disable` |

`stop` останавливает Soloist до ручного запуска или перезагрузки, если автозапуск включён.

`disable` отключает автозапуск и сохраняется после перезагрузки, но уже работающую музыку не останавливает. `enable` включает автозапуск; для немедленного запуска используйте `start`.

Чтобы полностью остановить Soloist и отключить его запуск после перезагрузки, выполните **`disable`, затем `stop`**:

```sh
sh /data/spotify-soloist/autostart.sh disable
sh /data/spotify-soloist/autostart.sh stop
```

## Ограничения

- **Голосовое управление не поддерживается:** управлять Spotify голосовыми командами через колонку нельзя.
- Работа проекта зависит от доступности API Spotify и Soloist.
- Совместимость с другими моделями Яндекс Станции не заявлена.

## Статус проекта

Проект предоставляется **«как есть»**, без гарантий стабильности, совместимости и дальнейшей поддержки. Используйте его на свой страх и риск.
